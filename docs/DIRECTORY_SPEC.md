# 资料目录规范

## 目录层级

```text
courses/
  公共基础课/
    课程名称/
      README.md
      笔记/
      复习提纲/
      练习与解析/
      历年资料/
      学习经验/
      资源链接.md
```

只创建实际用到的目录，不需要一次建立全部类型。Git 不跟踪空目录，首次创建时放入真实资料与说明即可。示例课程只作为说明模板保留；不要把实际资料放进示例课程。

- 一级类别：优先使用公共基础课、专业基础课、专业课、通识选修课；新增类别需说明理由。
- 二级课程：使用课程正式名称，不用简称。必要时以括号注明专业方向，避免同名混淆。
- 三级类型：按上述中文名称组织。允许公开的往年试卷、回忆整理需在“历年资料”中进一步区分，文件说明必须标明性质。
- 学年、教材版本、适用范围写入文件名和课程 README，不按投稿人的姓名建立目录。

## 文件命名

格式：`课程名_资料类型_适用学年或未知_主题_v版本.扩展名`。

示例：`高等数学_复习提纲_2025-2026_导数与微分_v1.0.pdf`。此处为命名示例，不代表仓库有该资料。

学年表示资料适用学年，不是上传日期；上传与修订日期记录在说明中。无关时间的经验资料可用“通用”，无法确定用“未知”。避免使用“最终版”“最新版”、仅数字文件名，以及 Windows 不支持的字符 `<>:"/\|?*`。文件夹和文件名不以空格或点结尾。

## 文件与说明

优先使用 Markdown、可检索 PDF；确有需要可提供 DOCX、PPTX、XLSX 或源代码，并说明打开方式。手写扫描件需清晰、方向正确、页码完整，尽量提供文字摘要。不收录未知程序、带恶意脚本的文档或加密包。

单个文件建议不超过 20 MiB；大文件先讨论，避免仓库不断累积二进制历史。不要通过拆分文件来规避限制。资源链接需记录标题、发布者、原始 URL、访问日期与失效替代方式，不提交含临时凭据的链接。

课程 README 必须有文件清单、作者公开昵称、具体来源、权限依据、适用范围和核对状态。核对状态可用“投稿者自检”“维护者抽检”“已纠错”，不得写“保证正确”。根课程索引只列课程，不重复维护全部文件列表。

## 版本更新

同一文件的小幅修改保留原文件名并记录修订；需要并存的不同教学版本另建文件并说明区别。二进制替换前核对是否有必要，避免无意义反复上传。删除或移动资料时同步更新所有相关链接。
