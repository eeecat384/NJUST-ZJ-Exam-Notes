# 权益与隐私反馈

发现未经许可的资料、个人信息、泄露凭据或其他不适合公开的内容时，请联系维护者处理。

## 反馈方式

普通问题可使用“权益与隐私反馈”Issue，提供文件路径、问题类型和最少必要描述。Issue 是公开的：不要粘贴身份证明、私人通信、涉事个人信息或秘密凭据，也不要再次上传问题文件。

如需提交敏感证据，请先通过维护者 GitHub 个人主页已公开的私密联系方式沟通。若维护者未提供私密渠道，可先开不含敏感细节的 Issue 请求建立渠道；如不适宜公开提及，可使用 GitHub 的举报或官方权利投诉渠道。维护者发布仓库时应在个人主页提供可用的私密联系渠道。

## 处理流程

1. 记录涉及路径及反馈类型，避免复制敏感内容。
2. 对可信的隐私或权利风险先暂时移除文件，再核验来源和许可范围。
3. 通过双方约定的私密方式核验证据，仅收集必要信息。
4. 决定恢复、脱敏替换或保持移除，并用不泄露隐私的方式记录结果。
5. 若内容已进入 Git 历史或 Fork，评估历史清理与平台协助；普通删除提交不代表历史内容已消失。凭据泄露时通知持有人立即撤销或轮换，不仅删除文件。

维护者不能保证清除他人 Fork、缓存或下载副本。请求方可补充证据申请复核；请勿通过重复公开敏感材料来证明问题。
