# NJUST-ZJ-Exam-Notes

南京理工大学紫金学院课程资料共享项目。

希望把同学们整理的笔记、复习经验与学习资源留存下来，减少重复寻找资料的时间，让经验能够被接续和修正。

> 本项目由学习者自发维护，与学校及任课教师无官方隶属或背书关系。资料仅供学习参考，课程安排、教学要求及考核范围请以当期正式通知为准。

## 从这里开始

- 查找资料：[课程索引](courses/README.md)。目前是初始仓库，尚未收录真实课程资料。
- 分享资料：[投稿指南](CONTRIBUTING.md)。每份资料必须附来源与授权说明。
- 报告错误：在仓库的 Issues 中选择“资料纠错”。
- 提出需求：在 Issues 中选择“资料需求”，请勿索要未公开试题或答案。
- 反馈权益或隐私问题：阅读[权益与隐私反馈](docs/RIGHTS_AND_PRIVACY.md)。

## 收录范围

欢迎原创课堂笔记、复习提纲、知识点总结、自编练习与解析、学习方法，以及允许转载的教学资料或公开资源链接。历年试题仅在有明确公开分享依据、符合相关考核要求且已完成脱敏时收录；无法确定时仅登记需求，不上传文件。

不收录未公开或正在使用的试卷、泄露答案、代写代考内容、未经许可的教材扫描件或付费课程、含个人信息的成绩单或名单，以及来源不明的文件。请勿上传账号、密码、访问令牌或绕过访问限制的方法。

课程文件夹按“课程类别 / 课程名称 / 资料类型”组织。每门课的 README 列明适用学年、文件用途、来源和使用权限。建议先读课程说明，再下载所需文件。

## 使用与贡献

资料可能存在错误或过时内容，请结合教材、课堂和独立推导核对。不要把往年资料当作本期考试范围保证，也不要提交他人的成果作为自己的作业。

可以通过 Pull Request 提交文件或修正；暂不熟悉 Git 的同学可先创建资料投稿 Issue，由维护者指导。Issue 中的附件同样会公开，请先检查授权与隐私。

所有投稿按[审核规则](docs/REVIEW_POLICY.md)处理。审核通过仅代表符合仓库收录要求，不代表学校认证或内容完全正确。欢迎在保留原作者署名与授权条件的前提下改进资料。

本仓库不对全部资料统一授予开源许可；各资料的权利和允许使用范围见对应说明。公开可见不等于可以任意转载、修改或商用，详见[授权政策](LICENSE_POLICY.md)。

感谢每一位愿意分享和纠错的贡献者。署名以投稿者选择的公开昵称为准；未经同意不公开真实姓名、学号或联系方式。
