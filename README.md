# 📚 南京理工大学紫金学院期末复习资料共享仓库

### NJUST Zijin College · Final Exam Study Resources

> 🎓 让复习更高效，让知识自由流动。

## 📖 项目简介

本项目旨在收集、整理和分享**南京理工大学紫金学院**各专业课程的期末考试复习资料，为同学们提供一个免费、开放、便捷的学习资源平台。

仓库内容包括课程知识点总结、期末复习提纲、个人学习笔记、典型例题及其他经过授权的学习资料。

希望通过大家的共同努力，减少重复整理资料的时间，让优质学习资源帮助更多同学。

**本项目由学生自发维护，与学校官方无关。**

## ✨ 项目特色

- 📖 **免费共享**：所有公开资料均可免费浏览
- 📁 **分类清晰**：按照课程类别整理
- 🔍 **方便查找**：通过目录快速定位课程
- 🤝 **共同建设**：欢迎同学们贡献原创或获授权的资料
- 🔄 **持续更新**：逐步补充和完善课程内容

## 🚀 如何使用

1. 在上方资料导航中找到对应课程。
2. 进入课程文件夹。
3. 点击需要的 PDF、Word 或其他资料。
4. 根据 GitHub 提供的预览或下载功能获取资料。

## 🤝 参与贡献

欢迎紫金学院的同学参与资料共享！

你可以：

- 分享自己整理的课程笔记
- 补充期末复习重点
- 修正现有资料中的错误
- 提出新的课程资料需求

可以通过 GitHub Issue 反馈建议，也可以通过 Pull Request 提交资料。

投稿前请确保拥有相应内容的分享权利，并删除个人敏感信息。
